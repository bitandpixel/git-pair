# plain-git profile changelog

## 1 — 2026-10-01

New. The floor for a repository that has not declared a workflow, and the machine-level default so that floor
exists everywhere.

Deliberately narrow: branch, commit at milestones, push before stopping, ask before any forge action. No
review protocol, no change record, no gate — and it says so rather than borrowing one profile's guarantees and
pretending to enforce them. The deferral lives in the description, because the description is the only thing a
harness reads before activating a skill.
